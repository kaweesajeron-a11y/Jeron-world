# Jeron World

A beginner-friendly personal entertainment website built with HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — dark theme, layout, and responsive styling
- `script.js` — mobile navigation, music filters, and current year
- `assets/jeron-profile.jpg` — add your own profile photo here

## Personalize before publishing
1. Add your own photo at `assets/jeron-profile.jpg`.
2. In `index.html`, replace `YOUR-EMAIL@example.com` and the sample social links.
3. Edit the About Me biography.
4. All music links are searches for current releases, not live charts. Replace or supplement them with links you trust.
5. Use photos, posters, and videos only when you have permission or a valid embed/link.

## Publish with GitHub Pages
1. Create a GitHub repository. For a simple project site, a name such as `jeron-world` is fine.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository's root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait a few minutes and open the published URL shown in Settings → Pages. A project site normally has a URL like `https://YOUR-USERNAME.github.io/jeron-world/`.

Keep private information out of a public repository. GitHub Pages hosts static sites; it does not process form submissions or run server-side code.
